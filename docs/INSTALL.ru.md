# Установка HSBG Overlay

По шагам: от чистого Mac до оверлея поверх игры.
[English version](INSTALL.md) · [назад к README](../README.ru.md)

## Что нужно

| | |
|---|---|
| macOS | 12 (Monterey) или новее, Apple Silicon или Intel |
| Hearthstone | установлен через Battle.net и хотя бы раз запущен |
| Python | 3.11 или новее, только если запускаешь из исходников — `setup.sh` предпочитает 3.13; у собранного `.app` свой внутри |

Оверлей работает **только на чтение** логов, которые игра пишет сама. Он не
читает память процесса, ничего не инжектит и не общается с серверами Blizzard.

---

## 1. Поставить Python 3.13

Пропусти, если `python3 --version` уже показывает 3.11 или новее.

```bash
brew install python@3.13
```

Нет Homebrew — поставь с [brew.sh](https://brew.sh) или возьми установщик с
[python.org](https://www.python.org/downloads/macos/).

## 2. Забрать код

```bash
git clone https://github.com/Dimus99/hsbg-overlay.git
cd hsbg-overlay
```

Без git: на странице GitHub **Code → Download ZIP**, распакуй и зайди в папку
через `cd` в терминале.

## 3. Создать окружение

```bash
./setup.sh
```

Скрипт делает `.venv` рядом с проектом и ставит туда PyObjC — в систему ничего
не устанавливается. На Apple Silicon он намеренно выбирает arm64-интерпретатор:
оверлей рисует через AppKit и должен совпадать с архитектурой машины.

Ожидаемый хвост вывода:

```
Done. Next:
  ./run.sh --check    check the environment
  ./run.sh            start the overlay
```

## 4. Проверить окружение

```bash
./run.sh --check
```

```
— Проверка окружения —
  папка логов        : /Applications/Hearthstone/Logs/Hearthstone_2026_08_21_02_18_13
  log.config         : в log.config уже есть всё, что нужно.
  язык игры          : ruRU (настройка: auto)
  полноэкранный режим: нет
  база карт          : 5738 карт, эффектов извлечено: 734
  Hearthstone запущен: да
  окно игры          : WindowRect(x=0.0, y=0.0, width=1440.0, height=900.0)
```

Что должно быть в каждой строке:

| Строка | Что хочешь увидеть |
|---|---|
| `папка логов` | путь. «не найдено» — значит игра ни разу не запускалась или стоит не в `/Applications/Hearthstone` |
| `log.config` | «уже есть всё, что нужно» или «дописан» — во втором случае **перезапусти Hearthstone**, шаг 5 |
| `язык игры` | локаль, в которой запущена сама игра; на ней оверлей и подписывает себя |
| `полноэкранный режим` | `нет`. `ДА` означает, что оверлей останется за игрой — см. шаг 6 |
| `база карт` | тысячи карт. Ошибка — значит на первом запуске не было сети; база качается один раз и дальше живёт в кэше |
| `окно игры` | размеры окна игры. Пусто — нормально, пока Hearthstone не запущен |

## 5. Один раз перезапустить Hearthstone

На первом запуске оверлей дописывает разделы `[Power]` и `[LoadingScreen]` в
`~/Library/Preferences/Blizzard/Hearthstone/log.config`. Hearthstone читает этот
файл **при старте**, поэтому разделы включаются только после перезапуска игры.
Без них лог молчит и оверлею нечего читать.

Выйди из игры полностью (⌘Q) и запусти заново.

## 6. Переключить игру в оконный режим

macOS не даёт рисовать поверх приложения в **эксклюзивном полноэкранном**
режиме — окно игры уезжает на отдельный Space. В игре: **Настройки → Графика →
Режим экрана → Оконный** или **Оконный без рамки**.

«Оконный без рамки» визуально не отличается от полноэкранного — обычно выбирают
его.

Разрешение на запись экрана **не требуется**: размеры окна берутся из публичного
списка окон.

## 7. Запустить

```bash
./run.sh
```

В строке меню появится значок **BG**. Оттуда можно скрыть оверлей, включить и
выключить кружки «?» на портретах оппонентов, включить журнал боёв или выйти.

Начни матч Battlegrounds — в углу окна игры появится главная плашка, а сверху по
центру, как только начнётся бой, встанет карточка с шансами.

## По желанию: собрать настоящее приложение

Чтобы запускать из Finder, а не из терминала:

```bash
./make_app.sh                 # собрать в dist/
./make_app.sh /Applications   # собрать и положить в /Applications
```

`HSBG Overlay.app` (~23 МБ) несёт свой Python и PyObjC, так что не зависит ни от
этой папки, ни от `.venv`. По двойному щелчку открывается окно с кнопкой
**Запустить / Остановить**, кнопкой проверки окружения и живым хвостом журнала.

Подпись ad-hoc — на своём Mac этого достаточно. Бандл, **скачанный** из GitHub
Releases, macOS помещает в карантин, и его нужно один раз снять:

```bash
xattr -cr "/Applications/HSBG Overlay.app"
```

## Обновление

```bash
git pull
./setup.sh     # только если менялся requirements.txt
```

Настройки и кэш карт лежат вне проекта, в
`~/Library/Application Support/hsbg-overlay/`, и переживают любое обновление.

## Удаление

```bash
rm -rf ~/Library/Application\ Support/hsbg-overlay
rm -f  ~/Library/Logs/HSBG-Overlay.log
rm -rf "/Applications/HSBG Overlay.app"     # если ставил приложение
```

Дальше удали папку проекта. Разделы, дописанные в `log.config`, можно оставить —
они ничего не стоят, и ими пользуются другие трекеры.

## Если что-то не работает

| Симптом | В чём дело |
|---|---|
| Оверлея нигде не видно | игра в эксклюзивном полноэкранном режиме. `./run.sh --check` скажет это строкой «полноэкранный режим» — переключись на оконный или оконный без рамки |
| Во время матча плашка пишет «Ожидание матча Battlegrounds…» | разделы лога ещё не включились: перезапусти Hearthstone один раз (шаг 5) |
| `папка логов: не найдено` | игра не запускалась после установки или стоит не в `/Applications/Hearthstone`. Оверлей смотрит ещё и в `~/Library/Logs/Hearthstone` |
| Нет названий карт, база карт с ошибкой | на первом запуске не было сети. Подключись один раз — дальше база в кэше, а `offline: true` в настройках вообще запретит ходить в сеть |
| Кружки «?» не совпадают с портретами | сбита зона наведения; запиши её по двум углам: `./run.sh --tool calibrate -- --set leaderboard` |
| `No virtualenv yet. Run ./setup.sh first.` | не выполнен шаг 3 или он упал — запусти ещё раз и прочитай вывод |
| Приложение не открывается («повреждено») | скачанный бандл под карантином: `xattr -cr "/Applications/HSBG Overlay.app"` |
| Шансы висят после боя | так и задумано: они гаснут на первом клике в таверне или через 60 секунд (`combat_hold_seconds`) |

Всё, что оверлей печатает, пишется ещё и в `~/Library/Logs/HSBG-Overlay.log` —
туда стоит смотреть первым делом, если запуск не удался.
